# ADR 001: language-runtime-policy

Status: Accepted

## Decision
Java 25 LTS owns business transactions; Node 24 is frontend tooling; TypeScript 5.9, React 19.3, Vite 8, PostgreSQL 18; future workers use ordinary Python 3.14 with uv.

## Consequences
Keep Phase 0 small; reconsider only with evidence and explicit review.
